# د پورونو حساب — Qarz Manager v2.0
Android offline debt manager.

Included:
- Dashboard
- My debts / debts owed to me
- People and individual account history
- Add debt
- Add payment
- Automatic remaining balance
- Today/month summaries
- Search-ready data structure
- Pashto/Dari/English language selector structure
- Local offline storage

Open the folder in Android Studio and Build > Build APK(s).
